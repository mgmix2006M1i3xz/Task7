Домашнее задание к работе номер 7

Условие задачи: Напишите программу, которая определяет, какая цифровая клавиша была нажата. Для ввода используйте getch(), объявленный в conio.h.

1. Алгоритм и блок-схема.

Алгоритм:

Начало.
Объявить символьную переменную key.
Считать символ с клавиатуры без эха (функция getch()).
Вывести нажатую клавишу на экран (так как getch её не отображает).
Проверить с помощью switch, является ли символ цифрой от '0' до '9'.
Вывести соответствующее сообщение.
Конец.

2. Реализация программы
   
(Примечание: для работы conio.h и getch() требуется компилятор под Windows, например, Visual Studio, Dev-C++ или MinGW. В онлайн-компиляторах Linux эта программа может не сработать).

#include <stdio.h>
#include <conio.h>
#include <locale.h>

int main() {

    setlocale(LC_ALL, "RUS");
    char key;

    printf("Нажмите любую цифровую клавишу: ");
    key = getch(); // Считываем символ без нажатия Enter

    printf("%c\n", key); // Показываем, что нажали

    switch (key) {
        case '0': printf("Была нажата клавиша: 0\n"); break;
        case '1': printf("Была нажата клавиша: 1\n"); break;
        case '2': printf("Была нажата клавиша: 2\n"); break;
        case '3': printf("Была нажата клавиша: 3\n"); break;
        case '4': printf("Была нажата клавиша: 4\n"); break;
        case '5': printf("Была нажата клавиша: 5\n"); break;
        case '6': printf("Была нажата клавиша: 6\n"); break;
        case '7': printf("Была нажата клавиша: 7\n"); break;
        case '8': printf("Была нажата клавиша: 8\n"); break;
        case '9': printf("Была нажата клавиша: 9\n"); break;
        default:  printf("Это не цифровая клавиша.\n"); break;
    }

    return 0;
}
